# プライバシーポリシー

「**英検®2級Pass**」（以下、「本アプリ」）は、ユーザーの個人情報を以下の方針に基づき適切に取り扱います。

---

## 1. 取得する情報
本アプリでは、以下の情報を取得する場合があります。

### (1) 広告配信に関する情報
本アプリでは、広告配信のために以下の情報が自動的に送信される場合があります。

- 端末に関する情報（機種、OS、広告ID 等）
- 広告の表示・クリックに関する情報

### (2) 利用状況に関する情報
アプリの品質向上および不具合改善のため、以下の情報を取得する場合があります。

- アプリの利用状況
- クラッシュ情報
- パフォーマンスに関するデータ

※氏名、住所、電話番号、メールアドレス等の  
**個人を直接特定できる情報は取得していません。**

---

## 2. 情報の利用目的
取得した情報は、以下の目的のために利用します。

- 広告の配信および最適化
- アプリの品質向上および不具合修正
- 利用状況の分析

---

## 3. 広告について
本アプリでは、第三者配信の広告サービス **Google AdMob** を利用しています。  
AdMob は、ユーザーの興味に応じた広告を表示するため、  
Cookie や広告ID等を利用する場合があります。

取得される情報や利用目的については、  
以下の Google のポリシーをご確認ください。

https://policies.google.com/technologies/ads

---

## 4. 第三者への情報提供
本アプリは、法令に基づく場合を除き、  
取得した情報を第三者に提供することはありません。  
ただし、広告配信や利用状況分析のため、  
必要な範囲で第三者サービスに情報が送信される場合があります。

---

## 5. 未成年の個人情報について
未成年の方が本アプリを利用する場合は、  
保護者の同意のもとで利用してください。
